# PrésenceManager - TP04

Ce projet est la suite des TP01, TP02 et TP03. Il ajoute la gestion des actions contextuelles sur le tableau de bord via une **CAB (Contextual Action Bar)** et un **PopupMenu**.

## Fonctionnalités ajoutées
- **Bouton CAB** : Ouvre une barre d'actions en haut de l'écran proposant deux actions :
  - *Afficher* : Ouvre une boîte de dialogue d'information.
  - *Terminer* : Ferme la barre d'actions.
- **Bouton Pop-up** : Ouvre un menu flottant ancré au bouton proposant deux actions :
  - *Ouvrir Groupes* : Navigue vers l'activité `GroupesActivity`.
  - *Informations* : Ouvre une boîte de dialogue d'information.
